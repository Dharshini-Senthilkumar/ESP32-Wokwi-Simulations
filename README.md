# ESP32 Sensor Simulations (Wokwi)

Sensor interfacing projects for ESP32, simulated on the Wokwi platform
during the Enthu Technology Solutions internship (May - June 2025).

## Projects

| Folder | Description |
|--------|-------------|
| DHT22 | Reads temperature and humidity |
| Ultrasonic | Measures distance with HC-SR04 |
| PIR | Detects motion and switches an LED |
| MQ2 | Reads gas / air quality level |
| LDR | Reads light intensity |
| OLED | Displays text on an OLED screen |

## Files in each folder
- `sketch.ino` - ESP32 program
- `diagram.json` - circuit wiring (can be opened in Wokwi)

## Tools
ESP32, Wokwi simulator, Arduino-style C++
